# Week 5 Project

This week focuses on databases, table creation, CRUD operations, and connecting PHP to dynamic frontend behavior.

## Features

- MySQL database scripts
- student table schema
- API routes for create, read, update, and delete
- statistics endpoint
- JavaScript frontend connected to the PHP backend

## Important Files

- `index.html`
- `app.js`
- `api.php`
- `config.php`
- `schema.sql`
- `database.sql`
- `Week5db.sql`

## Setup

1. Start Apache and MySQL in XAMPP.
2. Copy the folder into `htdocs`.
3. Import `database.sql` or `Week5db.sql`.
4. Copy `.env.example` to `.env` if you want to override the database connection string.
5. Open the project in your browser and test add, view, edit, and delete actions.
