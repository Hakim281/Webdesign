Nyumbani Luxe setup with XAMPP

1. Copy the folder `real-estate-portal` into `C:\xampp\htdocs\`.
2. Open XAMPP Control Panel and start Apache and MySQL.
3. Open phpMyAdmin at `http://localhost/phpmyadmin`.
4. Import the file `database.sql` from this folder.
5. If your MySQL uses the default XAMPP credentials, keep `config.php` as:
   - host: 127.0.0.1
   - port: 3306
   - database: real_estate_portal
   - user: root
   - password: blank
6. Open `http://localhost/real-estate-portal/register.php`.
7. Create a new account, then log in to access the protected website.

Included files
- `index.php`: protected real estate homepage
- `login.php`: member login page
- `register.php`: account creation page
- `logout.php`: logout action
- `auth.php`: shared session and database helpers
- `assets/images/`: your provided property images plus the background image
- `assets/images/design-reference.png`: the screenshot reference kept in the project
