# Week 4 Project

This week focuses on server-side processing, PHP form handling, authentication, sessions, and backend project organization.

## Features

- user registration with validation
- login form with password verification
- session-based protected portal
- MySQL database connection
- property dashboard populated from the database
- contact/viewing request form saved to the `contact_requests` table

## Important Files

- `login.php`
- `register.php`
- `index.php`
- `auth.php`
- `database.sql`
- `Week4db.sql`
- `setup.txt`

## Setup

1. Start Apache and MySQL in XAMPP.
2. Copy the folder into `htdocs`.
3. Import `database.sql` or `Week4db.sql` into phpMyAdmin.
4. Update `config.php` if your MySQL credentials are different.
5. Open the project in your browser and test registration, login, and viewing request submission.
