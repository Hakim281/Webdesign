# BIT3208 Project Submission

This repository is organized to match the Week 4 and Week 5 lesson requirements for Advanced Web Design and Development.

## Folder Structure

- `Week1/` placeholder for environment setup, wireframes, and early exercises
- `Week2/` placeholder for interface design and planning work
- `Week3/` placeholder for JavaScript, DOM, and PHP basics
- `Week4/` PHP authentication, form processing, session handling, and database-backed contact requests
- `Week5/` student management CRUD system with PHP, MySQL, and frontend integration
- `Documentation/` weekly logbook and GitHub submission notes

## Week 4 Summary

The Week 4 project is a protected real estate portal built with PHP and MySQL. It includes:

- registration form
- login form
- session-based protected dashboard
- database connection
- form validation
- contact/viewing request form saved to MySQL

## Week 5 Summary

The Week 5 project is a student management system built with PHP, MySQL, HTML, CSS, and JavaScript. It includes:

- database creation scripts
- student table schema
- CRUD operations
- live statistics
- backend API integration

## GitHub Workflow

1. Create a GitHub repository.
2. Add the remote:

```powershell
git remote add origin <your-github-repository-url>
```

3. Stage the submission:

```powershell
git add .gitignore BIT3208_Project
```

4. Commit the work:

```powershell
git commit -m "Add BIT3208 Week 4 and Week 5 submission"
```

5. Push to GitHub:

```powershell
git push -u origin <branch-name>
```
